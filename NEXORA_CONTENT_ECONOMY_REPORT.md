## Addendum: Infinite Rocket and expanded progression — source build only

Updated: 2026-10-10

This addendum records the current implementation on the local source branch. **It is not deployed to `marc-a2`**. The live server remains on the previously reported NexoraCore and NexoraTrading JARs.

- `nexora:infinite_rocket` is defined as a MYTHIC `FIREWORK_ROCKET` with the Eternal Thrust description and a stable per-instance UUID. The interaction listener calls Paper's native Elytra boost only while the player is gliding with an Elytra equipped, cancels the interaction, does not remove the custom item, uses a UUID-wide configurable cooldown (default 1,500 ms), caps horizontal/vertical boost velocity, and emits a launch sound plus particles. The Paper API compilation succeeds. No live anti-cheat or real-client Elytra flight test has been run (`NOT TESTED`).
- The Recipe Registry now contains 50 resource collections, raw → enchanted → double-enchanted recipes, Enchanted Coal/Iron Block intermediates, five requested EPIC components, and the final Rocket recipe. All 13 combined recipe gates include the final eight specified milestones plus every component-specific requirement. Multiple collection prerequisites are now evaluated together during retroactive unlock reconciliation. The Recipe Book displays missing Collection tiers, material counts, component links, and pages.
- `CraftingCostCalculator` expands the full nested recipe graph using arbitrary-precision quantities and optional market/production inputs. One Rocket requires, at current recipes, 819,200 coal; 409,600 iron ingots; 7,680 redstone; 5,120 each of gunpowder, blaze rods, and magma cream; 2,560 each of glowstone dust, gold ingots, diamonds, feathers, and leather; 3,840 quartz; 1,280 each of ender pearls and obsidian. Total: **1,271,040 raw units**. This reflects 160 matching units per Enchanted material and 160 Enchanted Coal/Iron per Enchanted Block. It is a very long progression goal; note the raw coal/iron requirements exceed the tier-X unlock threshold (100,000), so unlocks do not imply enough ingredients to craft it.
- At current YAML reference prices (minor units converted to Coins), the known inputs sum to **383,808 Coins plus the unconfigured Feather market value**. This is a static reference-price estimate, not a live Bazaar quote or guaranteed trade value. Manual/minion time remains unknown because production rates for every input have not yet been calibrated; no fake time estimate is reported.
- The item registry now explicitly classifies trading eligibility, and the Rocket is categorized as a standardized Bazaar item eligible for Auction House trading. The Auction House already stores full serialized item snapshots. The Bazaar still stores only material and quantity: standardized item escrow, claim snapshots, shared listing reservations, safe NPC exclusion, and the Bazaar GUI entry are **not yet implemented**. Therefore the Rocket is intentionally not registered as a live Bazaar product and no Rocket NPC quote exists.
- To preserve the stable Core JAR, the progression add-on writes only explicitly observed new resource drops into the existing Core collection table; it excludes the original 17 Core tracks and records player-placed block coordinates so those breaks do not count. The extended resource list is not yet shown in the Core Collection overview.
- NexoraProgression built with Java 21 against Paper 1.21.11; **15 tests passed, 0 failures, 0 errors**. Add-on JAR SHA-256: `1d75f9487391d1c0973c80bc8fdaa4e85e52b850c92fc6d4a5902fd0c36e1467`. Tests cover combined collection prerequisites, recipe dependency/cost expansion, and Elytra eligibility/cooldown/velocity caps. Core source and production JAR remain unchanged. Not yet covered: live event integration, anti-cheat, item-serial reservations, Bazaar/AH cross-listing, player-client testing, load/performance, or deployment/restart recovery.
