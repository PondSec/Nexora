# NEXORA NETWORK – SkyBlock

Deployable Paper 1.21.11 project for `marc-a2`. The Minecraft files, profiles and backups live on the dedicated SSD at `/opt/nexora`.

## Current state

- Paper 1.21.11 build 132 on Java 21, pinned Docker image, Compose-managed, online authentication enabled.
- Server-list icon is the supplied NEXORA pixel-art logo at `assets/server-icon.png`; the same 64×64 PNG is deployed as `/opt/nexora/minecraft/server-icon.png` and is included in Paper's status response.
- Hub world (`nexora_hub`) and original NEXORA plaza generated by NexoraCore; `nexora_mining` and `nexora_farming` worlds initialized.
- BentoBox 3.13.0, BSkyBlock 1.20.0, Level 2.22.0, LuckPerms, PlaceholderAPI, Multiverse-Core and VaultUnlocked are installed.
- NexoraCore stores UUID profiles, exact integer-minor-unit Coins, skill XP and collection counters in SQLite WAL mode. It registers a Vault economy provider.
- NexoraCore includes persisted nonlinear SkyBlock levels (up to 100), four skills (up to 50), once-only collection/skill/minion/area rewards, and transactional daily gathering quests.
- Each player receives an in-place refreshed individual sidebar and a protected NEXORA compass in hotbar slot 9. Its main menu links to Profile, Progression, Skills, Collections, Minions, Daily Tasks, Hub, private island, Mining Realm and Farming Realm.
- Survival rules prevent hunger, keep inventory and experience on death, protect tools/weapons from durability damage, and charge half of a player's Coins purse after death except on their own BentoBox island.
- Automated SQLite and progression tests cover profile isolation, restart persistence, economy limits, idempotent claims, minion production and the death purse calculation (12 tests pass).
- Nexora minions have 12 resource types, item crafting, island permission validation, T1–T11 upgrades, persistent storage, capped timestamp production and chunk-load recovery. Collection policy is direct player gathering only; minion output does not add collection progress.
- Whitelist and whitelist enforcement remain enabled. Minecraft TCP 25565 binds only to the DMZ host address `192.168.30.50`; OPNsense forwards WAN TCP 25565 to the Nginx stream proxy at `192.168.30.3`, which relays to Paper.

The deployed recipe book currently provides 18 configurable, collection-gated compression recipes through `/recipes`. On the separate `nexora_farming` world, five farm animal species are kept at 32 each, spread across the existing farm area. Crop growth modifiers are doubled only in that world; its 30 crop chunks are force-loaded so growth continues without nearby players. The full requested collections/crafting progression engine remains unfinished: Bazaar, Auction House, fuel/compactor/autosell minion add-ons, the expanded collection/milestone/reward catalog, custom equipment and abilities, broader anti-farm and resource-world progression, hub NPCs, full async SQL migration, multiplayer concurrency tests and a full restore drill remain pending. Skills and collection progress are recorded on eligible uncancelled block breaks; Bazaar purchases and Minion output do not award collection progress. The Hub world and menu layout were left unchanged.

See `docs/DEPLOYMENT_REPORT.md` for the pass/fail/not-tested matrix and `docs/` for operational details. Public TCP forwarding is configured. DNS-over-HTTPS now confirms the Minecraft SRV record resolves to `nexora.pondsec.com:25565` and the host A record resolves to the WAN IP.
